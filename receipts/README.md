# Receipts

Each file is the `receipt.json` a Cradle `stove_build` wrote for the build
named in the README's Observed section: the upstream release and commit, the
recipe's and the patches' SHA-256, the compiler (and, for open5, the SHA-256
of its own programs), the SDK input, the base sets, and the program's and the
data archive's SHA-256 and size. Copied from the job's output unchanged
(their SHA-256 match the job's).
